# RB Project Bridge

Aplicativo desktop para exportar projetos do Base44, auditar e sanitizar o código, gerar backup e publicar com segurança no GitHub.

## Estado

Versão atual: **0.1.1 RC1**

O projeto inclui:

- autenticação Base44 pelo fluxo oficial;
- exportação e backup com SHA-256;
- sanitização e scanner de segredos;
- inventário de dependências Base44;
- validação de build em cópia isolada;
- criação de repositório, commit e push no GitHub;
- interface desktop Electron;
- workflow GitHub Actions para gerar instalador Windows.

> Este commit inicial é substituído pelo código completo na sequência da publicação automatizada.
